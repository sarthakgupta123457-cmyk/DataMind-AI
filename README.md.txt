# DataMind AI — AI-Powered Data Analysis Agent

DataMind AI is a Python-based data analysis application built with Streamlit. It helps users upload datasets, explore their data, generate visualizations, and understand important insights through an interactive interface.

## Features

- Upload datasets for analysis.
- Explore and inspect data.
- Perform basic data analysis.
- Generate visualizations and charts.
- Interact with data through a simple web interface.
- Support for common data analysis workflows.

## Tech Stack

- Python
- Streamlit
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/sarthakgupta123457-cmyk/DataMind-AI.git
```

### 2. Open the project folder

```bash
cd DataMind-AI
```

### 3. Install dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the application

```bash
python -m streamlit run app.py
```

The application will open in your web browser.

## Project Purpose

The goal of DataMind AI is to make data analysis more accessible through an interactive application that helps users explore datasets and understand data visually.
